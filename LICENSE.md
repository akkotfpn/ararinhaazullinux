# Licenciamento do Ararinha Azul Linux

| O quê | Licença | Por quê |
|---|---|---|
| Código do sistema (Ninhada, Pena, Muda, Ninho, Plumagem, Bando etc.) | **GPL-3.0-or-later** ([texto](licencas/GPL-3.0.txt)) | Ninguém pode pegar o sistema, fechar o código e vender como se fosse seu. Melhorias voltam para a comunidade. |
| Bibliotecas e SDK para desenvolvedores de apps (`sdk/`) | **Apache-2.0** ([texto](licencas/Apache-2.0.txt)) | Qualquer empresa pode criar apps para o Ararinha, até apps fechados, sem medo. Inclui proteção de patentes. |
| Arte (logo, ícones, papéis de parede, sons, fontes próprias) | **CC BY-SA 4.0** ([texto](https://creativecommons.org/licenses/by-sa/4.0/legalcode.pt)) | Pode ser reutilizada citando o projeto e mantendo a mesma licença. |
| Documentação | **CC BY-SA 4.0** | Idem. |
| Pacotes de terceiros (kernel, Mesa, Wine…) | Licença original de cada um | Mantida e listada em cada receita. |

O nome "Ararinha Azul Linux" e o logo identificam o projeto oficial. Versões
modificadas devem usar outro nome, para que usuários saibam o que estão instalando.

O arquivo `LICENSE` na raiz contém a GPL-3.0, que é a licença padrão do repositório
quando uma pasta não indicar outra.

Decisão registrada no [ADR 0008](docs/adr/0008-licenciamento.md).
